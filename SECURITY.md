# Security Policy

## Supported Versions

Only the latest version on the `main` branch receives security fixes.

## Reporting a Vulnerability

Please **do not** open a public issue for security problems.

Report vulnerabilities privately via GitHub's
[private vulnerability reporting](https://github.com/MarioAer/claude-skim/security/advisories/new).

You can expect an initial response within 7 days. Once the issue is confirmed,
a fix will be prepared and a security advisory published when appropriate.
